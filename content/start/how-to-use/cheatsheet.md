# Cheat sheet: How to use LLD Guide

## The modules

Start here → OOP & SOLID → Design patterns → UML → Case studies. Read in order the first time.

## Lesson + cheat sheet

- Lesson: learn it properly (design, reasons, code).
- Cheat sheet: revise it in under two minutes. **Cheat sheet** button on every lesson; all of them in **Revise**.

## In the reader

- Tap a class in a diagram to trace it; *step through* sequence diagrams.
- Dotted underline in code = explained in the lesson; tap it.
- **Aa** for text size; the app reopens a lesson where you stopped.

## Before an interview

1. Revise the topics on the job description.
2. Recall mode: answer out loud, then reveal.
3. End with each case study's 30-second pitch.
